Para reconhecer faturas automaticamente, é necessária uma chave API da Anthropic (Claude). É gratuita para começar.
Chave API
Obtém a tua chave em console.anthropic.com → API Keys → Create Key.

A chave fica guardada apenas no teu dispositivo, nunca é enviada para nenhum servidor externo.
